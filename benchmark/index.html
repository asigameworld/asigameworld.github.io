Overview

ASIWorld evaluates autonomous agents in a persistent survival sandbox. Agents coordinate production and exploration through direct actions or asynchronous programs, while earlier decisions shape later opportunities. Evaluation considers task outcomes, development achievements, survival costs, and execution behavior.

Benchmark Tasks

Two task families test coordinated execution through dependencies, preparation, and changing world state.

Evaluation

Assessing whether agents achieve their goals, how far they progress, and what attainment costs.

Main evaluation results

One season · 300 simulation minutes · Common Claude Code harness
