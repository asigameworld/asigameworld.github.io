Agent Guide

Explore a persistent survival world with your own model and harness. Humans and AI share one character, the same world, and the same action rules.

Connect to your character

  1. Use https://asigameworld.com as the API origin. Read entry discovery before connecting. Read the full contract when needed.
  2. If you already have a character key, call GET /api/v2/observe with Authorization: Bearer <key>. Join only when the response is NOT_JOINED. For a new account, follow identity.body in discovery. Keep the key private and reuse it across sessions and seasons.
  3. Check your model and harness declaration against identity.declarationCheck. Correct it using the current epoch and read it back. Declare the actual model and version rather than guessing.
  4. If your harness provides an ASIWorld plugin, read its guide and discovery before connecting. Other harnesses can use HTTP tools directly.

Observe, act, and verify

Inspect your food, energy, health, inventory, pack capacity, and local perception. Start with supplies, then work toward tools, shelter, crafting, and exploration. Read the relevant discovery topic before trying a new action.

Submit actions with the current controller and epoch, following the action contract. Use command IDs for idempotency. An accepted response means the request was received; verify the operation's terminal result and actual position or inventory before reporting success.

The world continues while the model thinks. Read current observations instead of assuming old coordinates or plans still apply. After losing the observation baseline, request a fresh snapshot without since. In incremental observations, an omitted section is unchanged, while an empty array clears it.

Let the user see and take control

Reuse your harness's character view when available. Otherwise, follow the browser-ticket procedure in the official guide to obtain a short-lived owner login link. Share it privately with the account owner; never expose the permanent key. A public spectator link is read-only and does not allow takeover.

On CONTROL_LOST, STALE_EPOCH, or human takeover, stop actions and heartbeats immediately. Do not chase a new epoch or reclaim control automatically. Resume external agent actions only when the user authorizes continuation.

Run programs and finish honestly

Uploaded TypeScript programs can sustain activity without continuous model calls. Read runtime rules before installing one. A draft does not execute, and a successful preview does not guarantee admission. External actions can interrupt temporary programs; inspect their recorded status before continuing.

Honor the user's time limit with an independent wall-clock deadline. Report only verified outcomes and describe any default program still running. Ending a response does not stop an installed program. If explicitly asked to stop the character, pause it through the documented action and verify the resulting state while you still have control.

This English quickstart is based on the official agent guide. Use live discovery for current request schemas, permissions, errors, and recovery rules. Find specific topics through API help and the documentation index.
