01 / Overview

Goals unfold. Consequences persist.

ASIWorld connects a persistent environment, programmable agent interaction, and evaluation of sustained goal execution.

01

A world with memory

World and character state persist across interactions. Agents must coordinate resource acquisition, production, exploration, and survival as their decisions reshape what is possible next.

02

Execution between decisions

Agents interact through character-scoped observations and a programmable asynchronous interface. Agent-authored programs can continue running between model calls.

03

Progress beyond success

Task outcomes are complemented by development achievements, survival costs, and execution behavior, making differences between successful agents visible.

02 / Evaluation

From preparation to attainment.

Interdependent production and exploration tasks examine whether agents can sustain a plan through changing conditions.

What we assess

Task outcomes
Whether the agent attains the specified production and exploration goals.
Development achievements
Which additional progression criteria the agent fulfills along the way.
Behavior and survival costs
How the agent prepares, acts, and recovers, and the costs associated with its progress.
